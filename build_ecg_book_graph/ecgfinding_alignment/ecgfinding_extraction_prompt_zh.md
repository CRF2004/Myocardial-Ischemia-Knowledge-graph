你的任务是将心电图（ECG）发现表述的表面形式（从教科书知识提取而来）与PTB-XL发现标签（候选列表）进行对齐。

目标是**严格的语义对齐**（本体风格），而非临床推理、诊断推断或基于证据的关联。

给定：
- 一个查询ECG发现（自由文本）。
- 一个按顺序排列的PTB-XL标签候选列表，每个候选包含字段：
  （scp_code, description, Statement Category）。

**对于每一个候选**，输出**恰好一个**关系类型：

- **MAPS_TO**
  仅当候选概念在语义上与查询概念**完全等价**时使用（真正的同义词/释义；相同发现含义）。

- **SUBTYPE_OF**
  仅当候选概念是查询概念的一个**严格子类型**时使用（候选 ⊂ 查询）。必须是清晰的“is-a”包含关系。

- **PART_OF**
  仅当查询本身是一个**组合型发现**（例如包含“and/with/伴随/同时/合并”等），且候选概念是查询中明确陈述的一个**原子组成部分**时使用。
  要求：候选必须能在查询中找到直接对应的语义片段（同义/释义可接受），但候选不需要覆盖查询的全部信息。
  
- **NONE**
  无有效的语义对齐。

**必须严格遵守的硬性规则：**

**1) 对齐与推理防火墙**
- **不要**基于“提示/表明/支持/证据/风险”进行映射。
- **不要**推断因果关系、诊断或临床意义。
- 如果关系是关于作为某疾病的证据，请选择 **NONE**。

**2) 概念类型门控**（仅内部使用；不要输出此类型）
在决定关系之前，**内部地**将查询和候选分类为：
- **MORPH**：波形/段形态学发现（例如，ST段抬高/压低，T波倒置，Q波，低电压）。
- **INTERPRETATION**：更高层次的解释（例如，缺血性ST-T改变，心内膜下损伤，心肌梗死）。
- **OTHER**：其他任何类型。

然后应用：
- 如果查询是 **MORPH** 而候选是 **INTERPRETATION** → 关系**必须**是 **NONE**。
- 如果查询是 **INTERPRETATION** 而候选是 **MORPH** → 关系**必须**是 **NONE**。
- 只有 **MORPH↔MORPH** 或 **INTERPRETATION↔INTERPRETATION** 才可能是 **MAPS_TO**/**SUBTYPE_OF**。

**3) 细节保留约束**（防止过度泛化的映射）
如果查询包含**任何**特定细节，例如：
    - 特定的导联/区域（例如，aVR, V1–V6, I, aVL, 下壁/前壁/侧壁），
    - 量化阈值（例如，≥1 mm），
    - 模式限定词（孤立的、弥漫性的、对应性改变、水平的等），
那么：
    - 只有当候选描述**保留了相同的关键细节**时，才允许使用 **MAPS_TO**。
    - 如果候选更笼统且**丢失了这些关键细节** → 关系**必须**是 **NONE**。
（**不要**在这种情况下使用 **SUBTYPE_OF**，因为 **SUBTYPE_OF** 要求候选 ⊂ 查询。）

**4) 禁止“仅类别”映射**
**不要**仅仅因为两者都提到ST/T/QRS这类宽泛的概念就进行映射。
通用词根（例如，“非特异性ST抬高/压低”、“T波异常”）**绝对不能**成为详细查询的万能匹配项。

**5) 子类型方向是单向的**（候选 ⊂ 查询）
- 仅当候选**明显比查询更具体**时，才使用 **SUBTYPE_OF**。
  示例：“前壁导联缺血性改变” **SUBTYPE_OF** “缺血性ST-T改变”。
- 如果查询比候选更具体，你**必须**选择 **NONE**（不要发明一个反向关系）。

**6) 稀疏性约束**（防止图谱过度密集化）
对于**同一个查询**的整个候选列表：
- 最多**一个**候选可以被标记为 **MAPS_TO**。
- 最多**一个**候选可以被标记为 **SUBTYPE_OF**。
- 所有剩余的候选**必须**是 **NONE**。
如果没有候选是完美匹配，则所有都输出 **NONE**。

**7) 不确定情况处理策略**
如果在 **MAPS_TO**/**SUBTYPE_OF** 和 **NONE** 之间不确定，选择 **NONE**。

**输出格式**（严格的JSON，无额外文本）：
{{
  "query": "<原始查询>",
  "alignments": [
    {{
      "scp_code": "<scp_code>",
      "candidate_description": "<候选描述>",
      "candidate_category": "<Statement Category>",
      "relation": "MAPS_TO" | "SUBTYPE_OF" | "NONE",
      "short_justification": "<仅解释语义等价性或is-a包含关系的1个短句；不要包含临床推理>"
    }},
    ...
  ]
}}
